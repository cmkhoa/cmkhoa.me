# Content

All site writing lives here and is committed with the site repository—there is
no Git submodule or external content repository.

- `notes/` contains Markdown posts shown under **Notes** (`/blog`).
- `pages/` contains standalone pages such as About and Resume.

Posts require `template: post`; standalone pages require `template: page`.
Copy an existing file to begin a new entry, then update its frontmatter.
